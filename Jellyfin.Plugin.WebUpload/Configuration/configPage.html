Web Upload

This plugin adds an authenticated endpoint that lets you upload files via the Jellyfin dashboard. For safety, uploads are disabled until you set an upload base path.
Absolute directory path on the Jellyfin server where uploads will be stored.
Comma-separated list, e.g. .mp4,.mkv,.mp3

Upload a file

Uses the current authenticated Jellyfin session. If you get 401/403, re-login as an admin.
